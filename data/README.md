# Data Directory

This benchmark is **entirely self-generated** — there is no external or
third-party dataset. All data are produced by the pipeline's own stage
scripts (PDE training runs, a synthetic planted-feature bank for the
positive control, and the FNO Green's-function regression dataset). The
provenance of the underlying benchmark assets is documented in
[docs/data_card.md](../docs/data_card.md).

## Contents

| File | Purpose |
|---|---|
| `manifest.json` | Machine-readable manifest: version, license, generator commit, per-file sizes + SHA256 for the **authoritative aggregate artifacts** (the slim re-analysis set). |
| `checksums.sha256` | Standard `sha256sum -c` format for the same files. |

## Verify a checkout

```bash
sha256sum -c data/checksums.sha256      # from the repository root
```

or, with only the manifest:

```bash
python - <<'EOF'
import hashlib, json
from pathlib import Path
m = json.load(open("data/manifest.json"))
bad = []
for f in m["files"]:
    h = hashlib.sha256(Path(f["path"]).read_bytes()).hexdigest()
    status = "OK" if h == f["sha256"] else "MISMATCH"
    if status != "OK":
        bad.append(f["path"])
    print(f"{status:8s} {f['path']}")
assert not bad, f"checksum mismatches: {bad}"
EOF
```

## Data source summary (per the checklist fields)

- **Dataset source:** generated by `experiments/run_pipeline.py` stages
  1–13 (commit `816bd2e`); FNO dataset generator:
  `operators/fno.py::green_function_dataset`; planted-feature bank:
  `experiments/positive_control.py::PlantedFeatureWorld`.
- **License:** CC BY 4.0 ([LICENSE](../LICENSE)).
- **Version:** 3.0.0 (2026-09-07).
- **Download URL:** the Git repository itself —
  https://github.com/shamiquekhan/PINN-Mechanistic-Interpretability
  (a Zenodo archival DOI will be added to `CITATION.cff` at first release).
- **Expected file names:** see `manifest.json`.
- **SHA256:** per-file digests in `manifest.json` / `checksums.sha256`.
- **Preprocessing:** none — figures and tables read the JSONs directly.
- **Splits:** run-level train/test splits for SAE training and monitors are
  seeded (numpy `default_rng(0)`; SAE splits `seed=0`); seed blocks for the
  qualification matrix are listed in
  [docs/reproducibility.md §7](../docs/reproducibility.md).
- **Random seeds:** per-run seeds are recorded in each run's
  `runs/<name>/config.json` and in every checkpoint manifest.
