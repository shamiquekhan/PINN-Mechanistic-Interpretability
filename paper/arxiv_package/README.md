## Submission checklist (arXiv)

1. **Verify the bib details** — `references.bib` was assembled from
   memory/secondary sources; confirm every entry (venue, year, pages)
   against the original papers before submitting. Entries to double-check:
   the 2025–2026 SAE-skepticism preprints (dois/venue may have changed
   since assembly) and the workshop versions.
2. Pick a primary category. Suggested: `cs.LG` (Learning); secondary
   `physics.comp-ph` (or `cs.AI`).
3. Comments field suggestion: "14-stage preregistered campaign; all
   numbers regenerate from committed artifacts; code at
   github.com/shamiquekhan/PINN-Mechanistic-Interpretability".
4. Upload `main.tex`, `references.bib`, `figures/`, `tables/` (arXiv
   compiles the TeX itself; include the PDF for the reader preview).
5. License: the repo is CC BY 4.0 for content; choose the matching
   arXiv license option (or the default non-exclusive).

## Number-grounding guarantee

Every number in the prose was transcribed from committed JSON artifacts
under `runs/` (see `scripts/check_results_grounded.py` for the
machine-checked registry). If any number fails to match an artifact,
CI fails before the docs land — regenerating tables/figures from
`runs/` reproduces every value in this paper.

## Claims discipline (important)

The operator causal battery (Section 6.2 / table_operator_causal) is
reported as a **suggestive asymmetry, NOT a confirmed causal boundary** —
the preregistered conjunctive rule fired H14b. Do not strengthen this
claim in the abstract or elsewhere without new preregistered evidence
(the amplify-vs-ablate criterion is registered as the follow-up).
