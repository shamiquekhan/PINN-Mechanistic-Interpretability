# Comprehensive Research Results & Benchmark Report (v2.1)

This document reports the quantitative empirical findings of the **PINN Mechanistic Interpretability** research campaign after the v2 revision (TopK SAEs, three mandatory causal controls, controller rollback fix, 10-seed statistics) and the **v2.1 negative-result hardening** (multiple-comparison corrections, planted-feature positive control, effective-rank analysis, monitor-source ablation, run-level CIs on monitor AUROC).

The headline is a *hardened negative mechanistic result* with a mechanistic explanation and a validated pipeline — plus a positive engineering result (the closed-loop controller) that is explicitly separated from the mechanistic claim. Every number is generated by `experiments/run_pipeline.py` and reproducible from `runs/`.

## 4. Causal Validation — the make-or-break result (v2.1 hardened)

88 feature evaluations (8 candidate features × 11 held-out boundary-starvation checkpoints), each against three controls: unrelated-feature ablation, norm-matched random-direction perturbation (per-row magnitude matched, 5-seed median in the positive control), and a **supervised linear-probe direction** (AXBench-style). Full probe coverage verified (the v2.0 run had a coverage bug where some features fell back to a random control; fixed and re-run).

### 4.1 Primary endpoint

| Quantity | Estimate | 95% bootstrap CI |
| :--- | :--- | :--- |
| **Causal strength $E_T$** | **−0.0002** | **[−0.0051, +0.0060]** |
| Specificity $S_{\text{spec}}$ | 1.23 | [0.97, 1.53] |
| Raw "beats all 3 controls" evaluations | 4/88 (4.5%) | — |
| **Bonferroni survivors** ($\alpha/m$, $m{=}8$) | **0/8** | threshold $p \le 0.00625$ |
| **BH-FDR survivors** ($q{=}0.05$) | **0/8** | chance expectation: 0.4 hits |

**Zero features survived multiple-comparison-corrected causal testing.** The $E_T$ CI includes zero; specificity straddles 1.0. The 4 raw wins at 4.5% is consistent with chance (expected ≈ 0.4–4 raw hits depending on the per-test rule); after Bonferroni or BH-FDR correction across the 8 features tested, nothing survives.

### 4.2 Sign diagnostic

All 88 target deltas are positive (ablation always *increases* PDE loss): the features encode activation energy required by the reconstruction, and *any* perturbation that degrades reconstruction shifts the loss comparably. This is the signature of features that are *representational*, not *causal* — ablating any active latent damages the decode; nothing direction-specific is present.

### 4.3 Probe-control comparison

The supervised linear-probe direction beats the SAE feature's causal effect outright in **9/88 (10.2%)** of evaluations and matches it elsewhere — AXBench-consistent (simple linear baselines ≈ SAEs), now as a measured comparison rather than an inference.

### 4.4 Positive control — the pipeline works (planted-feature experiment)

Before trusting a null, we verified the machinery can detect a *known* causal feature. Synthetic activations with planted sparse ground-truth (128 features in 64 dims, superposition regime) were run through the **exact** SAE + hook + intervention + scoring battery (`experiments/positive_control.py`, artifact `runs/positive_control.json`):

| Measurement | Value |
| :--- | :--- |
| SAE recovery of planted feature (decoder cosine) | **0.99** |
| Targeted ablation Δ target loss | **+0.024** |
| Random-direction control Δ (median of 5 trials) | 0.0003 (spread ≤ 0.0016) |
| Unrelated-feature control Δ | ~0 |
| Probe-direction control Δ | ~0 |
| **Pipeline verdict** | **PASS** — targeted effect 15× all controls |

The pipeline recovers and causally validates a planted feature when one exists. The PINN null is therefore attributable to **the PINN activations**, not to a machinery bug.

## 5. Why PCA wins: the activations are not in superposition (effective-rank analysis)

The most informative number in this study (`analysis/effective_rank.py`, artifact `runs/effective_rank_analysis/effective_rank_report.json`):

| Statistic (64-unit hidden layer, all runs) | Value |
| :--- | :--- |
| **Participation ratio of activation covariance** | **1.34 mean (range 1.03–1.53)** |
| PCA components for 95% energy | 1.83 mean |
| PCA components for 99% energy | ≤ 5 |
| Superposition ratio (PR / 64 dims) | **0.021** |

**The 64-dimensional hidden activations live on an effectively 1.5-dimensional manifold.** A 1D-input PINN evaluated on a 1D probe grid produces a 1-parameter family of activation vectors — a smooth curve through activation space. There is no superposition because there is nothing to superpose: the network encodes far fewer effective features than it has neurons.

This single measurement explains every negative SAE result simultaneously:
- **Why k-matched PCA beats the SAE 12×** — the data is (sub)linear and low-rank; PCA is the *correct* tool.
- **Why 51–70% of SAE latents are dead and only 1/256 features are seed-stable** — an overcomplete sparse dictionary has no genuine features to find on a rank-1.5 manifold; what it recovers is arbitrary partitions of a curve, which differ run to run (consistent with Leask et al. 2025).
- **Why causal interventions show no specificity** — latents carve up a curve; ablating any segment damages the decode without direction-specific loss effects.
- **Why `data_std` (run identity) is the strongest correlate** — the activation curve's *thickness* separates regimes, and everything else is geometry along one dimension.

**Implication for the field:** interpretability tools validated on LLM residual streams (where superposition is abundant) may not transfer to small scientific networks trained on narrow, low-dimensional objectives. We state this as a **scoped negative result**: nothing here rules out SAEs on wide PINN ensembles, higher-dimensional PDE parameterizations, or operator-learning models (FNOs, DeepONets) where the effective rank of representations is plausibly much higher. Testing that boundary is the natural follow-up.

### 5.1 Width-scaling follow-up

To test whether raw width alone creates superposition, the fixed 1D Poisson task was trained for 1,000 steps at widths 16, 32, 64, 128, 256, and 512. The local tangent rank was 1 at every width, while covariance PR stayed between 1.74 and 2.00:

| Width | PR | Stable rank | Local tangent rank | PCA components (95% / 99%) |
| :---: | ---: | ---: | ---: | ---: |
| 16 | 2.000 | 1.349 | 1 | 2 / 3 |
| 32 | 1.895 | 1.278 | 1 | 2 / 3 |
| 64 | 1.823 | 1.217 | 1 | 2 / 3 |
| 128 | 1.740 | 1.175 | 1 | 2 / 2 |
| 256 | 1.965 | 1.432 | 1 | 2 / 3 |
| 512 | 1.795 | 1.119 | 1 | 3 / 4 |

This supports the narrower claim that increasing width without increasing task or input complexity did not produce observed superposition in this benchmark. It is a single-seed follow-up and does not establish a universal width law. Artifact: `runs/width_scaling/width_scaling_report.json`.

## 6. Early-Warning Monitors (run-level splits, leakage-audited, with CIs)

Trained on 40 runs, evaluated on **18 held-out runs**, failure steps derived from each run's own trajectory. Leakage audit: 0 violations. **Run-level bootstrap CIs** on AUROC (2,000 resamples of held-out runs — the independent unit):

| Monitor | AUROC | AUROC 95% CI | AUPRC |
| :--- | :--- | :--- | :--- |
| Loss-only threshold | 0.468 | [0.406, 0.511] | 0.233 |
| Conventional logistic | 0.872 | [0.795, 0.953] | 0.748 |
| SAE + conventional | **0.878** | **[0.806, 0.958]** | 0.755 |

The conventional and SAE-augmented monitors are clearly above the loss-only threshold on this held-out split; their CIs overlap, so the small SAE increment is not established. The loss-only monitor remains compatible with chance. These results support predictive monitoring of the configuration-determined failure mixture, but do not establish that SAE features add predictive value beyond conventional signals.

## 7. Closed-Loop Controller — rescue, baselines, and the monitor-source ablation

The v1 controller demo reported a "recovery" to $L_2 = 0.579$ (worse than its 0.279 start). Root causes (no-op rollback, untracked rel_l2, underpowered rebalancing) were fixed in v2; v2.1 adds the **monitor-source ablation** that measures — rather than asserts — what drives the rescue.

### 7.1 Three-arm rescue comparison

| Arm | Final rel $L_2$ | Best | Interventions | Rollbacks |
| :--- | :--- | :--- | :--- | :--- |
| **Closed-loop controller** (conventional signals) | **0.0166** | 0.0116 | 8 | 1 |
| No-action | 0.2953 | 0.2789 | 0 | 0 |
| Oracle reweight ($\lambda{=}$1,1 from step 0) | 0.0119 | 0.0119 | 0 | 0 |

### 7.2 Monitor-source ablation (v2.1)

Identical controller and actions; only the alarm source differs — SAE feature activity vs a **matched-dimensionality random-feature monitor** (fixed random projection, same top-8 sparsity budget):

| Arm | Final rel $L_2$ | Interventions |
| :--- | :--- | :--- |
| SAE-feature monitor | 0.0236 | 10 |
| Random-feature monitor | 0.0236 | 10 |
| Conventional (loss/$L_2$) monitor | **0.0166** | 8 |

The SAE- and random-feature arms produce **bit-identical rescue trajectories** (verified equal at every step, `controller_comparison.json: trajectories_bit_identical=true`). Both activity signals rise with training instability, and the bounded rebalancing action is rate-limited by cooldown and confirmation — not by the monitor's fine structure. The conventional loss/$L_2$ monitor is *slightly better* (fewer interventions, lower final error).

**Measured conclusion:** the SAE features are inert cargo in the closed loop. The rescue is attributable to the controller machinery driven by any instability-correlated signal — with the conventional signal best. This ablation converts "driven by conventional signals" from an inference into a citable measurement.

### 7.3 Honest scope

This validates the *controller engineering* (bounded actions, genuine rollback, verifiable per-step logging, rescue vs no-action/oracle baselines). It is **not** evidence for SAE features, and the two claims are kept structurally separate throughout.

## 8. Claim ladder — where the evidence lands

1. **Representational claim — WEAKENED TO EXPLAINED-NULL.** Strong directional associations with physics quantities exist (r = 0.20–0.75, beating random controls 8–32×), but the effective-rank analysis shows the activation manifold is a ~1.5-dimensional curve: the "features" are coordinates along geometry, not superposed concepts. The strongest association (`data_std`, r = 0.999) is a labeled run-type confound.
2. **Causal claim — REJECTED (hardened negative).** $E_T$ CI includes zero; 0/8 features survive Bonferroni *or* BH-FDR; all target deltas sign-consistent with representational (not causal) encoding; probe directions match or beat SAE features. The planted-feature positive control PASSES, so the null is attributable to the PINN activations, not the pipeline.
3. **Predictive claim — SUPPORTED WITH SCOPE.** Conventional and SAE-augmented monitors discriminate the held-out failure mixture (AUROC 0.872 and 0.878), while the loss-only threshold is near chance; the overlapping CIs do not show an SAE advantage.
4. **Prevention claim — SUPPORTED FOR CONTROLLER MACHINERY ONLY, AND NOW MEASURED.** The closed-loop controller rescues boundary starvation (0.295 → 0.017; beats no-action 18×; within 1.4× of oracle), and the monitor-source ablation proves the SAE features contribute nothing — the rescue runs on conventional signals.

**The paper this evidence supports:** *"We built and preregistered a full mechanistic-interpretability pipeline for PINN failure diagnosis — failure atlas, TopK SAEs with mandatory PCA/random/probe controls, planted-feature positive control, multi-view feature dictionary, multiple-comparison-corrected causal battery, leakage-audited monitors with run-level CIs, and a rollback-capable closed-loop controller — and found that SAE-derived features provide no causal information beyond matched controls in this benchmark. Effective-rank analysis explains why: these PINN activations are not in superposition (participation ratio ≈ 1.3 of 64 dimensions), so sparse dictionary learning solves a problem that does not exist here, while a conventional-signal-driven controller meaningfully reduces failure rate independently of interpretability. The negative result is consistent with recent SAE-skepticism findings (Korznikov et al. 2026; Leask et al. 2025; Wu et al. 2025) and identifies low-rank scientific-network representations as a concrete regime where SAE methodology adds no validated value."*

**Limitations (scoped, explicit):** this does not rule out SAEs on wider PINNs, ensembles, higher-dimensional parameterizations, or operator learners (FNOs/DeepONets); the monitor result is specific to this held-out failure mixture and window protocol; gradient-conflict and collocation-starvation were stress-tested but excluded from final failure-class claims because their operational labels did not reproduce cleanly.
